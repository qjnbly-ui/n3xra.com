# N3XRA Virals V1 Roadmap

## V1 Goal

Ship one strong workflow:

```txt
Paste reference -> Extract Framework -> Generate Posting Pack
```

The workflow should function before accounts, subscriptions, trend databases, or advanced tracking systems are added inside Virals. V1 can run as a frontend-only localStorage prototype so we can test the product direction before paying for another backend.

## V1 User Flow

1. User opens the Framework Analyzer.
2. User pastes a TikTok URL, Daily Virals reference, product name, niche, goal, and optional notes/transcript.
3. Local prototype generates a structured framework analysis.
4. UI displays hook type, hook formula, body framework, psychological triggers, conversion logic, keep/change guidance, hooks, scripts, captions, and shot list.
5. Results are saved locally in the browser.
6. Later, the same workflow connects to AI, data provider APIs, Master login, and Virals Supabase.

## V1 Build Order

1. Build frontend-only Framework Analyzer.
2. Add local saved framework library.
3. Add mock framework detection and posting pack generation.
4. Test workflow with real Daily Virals/TikTok examples.
5. Add AI endpoint for real structured analysis.
6. Wire endpoint to Virals Supabase when storage is worth paying for.
7. Add Master login and product access gating.

## Deferred

- trend discovery database
- scheduled trend ingestion
- competitor monitoring
- product research dashboards
- creator tracking dashboards
- subscriptions inside Virals
